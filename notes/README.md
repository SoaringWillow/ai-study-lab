# 学习笔记

一次会话一条，文件名 `YYYY-MM-DD.md`，150–300 字，固定三段：

```markdown
# 2026-08-24 · <今天学的东西>

**我原以为**：…

**现在知道**：…

**还不懂**：…
```

这一步不做，前 60 分钟的深工作会在两周内蒸发。写完就算这次会话交付了。

每天的 90 分钟时间盒：

| 时段 | 做什么 |
|---|---|
| 0–10 min | 回忆：不看资料写下上次学到的三点，或过 20 张 Anki 卡 |
| 10–70 min | 单线深工作：一节课 / 一篇论文 / 一段代码，不切换主题 |
| 70–90 min | 输出：写这条笔记 |

低能量日的 20 分钟版本：Anki + 扫一遍当日 arXiv `cs.RO` 标题 + 读一篇摘要。目的只有一个：链条不断。
