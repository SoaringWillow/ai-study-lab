# 动手项目阶梯

每个实验一个目录：`experiments/Pn-<名字>/`，里面至少有 `README.md`（目标、做法、结果、失败归因表）。

| # | 项目 | 周期 | 成本 | 交付物 | 状态 |
|---|---|---|---|---|---|
| P1 | MuJoCo + mujoco_menagerie：机械臂 IK + 轨迹跑通，搞懂 timestep / 接触 / 求解器 | 2 周 | ¥0 | notebook + 「仿真到底在算什么」笔记 | ☐ |
| P2 | LeRobot 上复现 ACT 与 Diffusion Policy（公开数据集），对齐论文指标 | 3 周 | GPU 按小时租 | 复现报告 + 失效模式对照表 | ☐ |
| P3 | 真机：SO-101 一对自采数据 → 训练 → 20 trial 真机评测 | 4 周 | $150–500 | 视频 + 失败归因表 | ☐ |
| P4 | 自采 500 episodes，4 组消融（数量 / 视角 / 演示者熟练度 / 纠错-恢复数据） | 6–8 周 | GPU | scaling 曲线 + 一个反直觉结论 | ☐ |
| P5 | 评测基准：把 P4 协议做成开源 harness，横评 3 个开源 VLA | 8–12 周 | GPU | 开源工具 + 技术报告 → 投 workshop | ☐ |

**硬件纪律**：先把机械臂玩到底再碰人形。一对 SO-101 覆盖 P3–P5 的全部学习价值。
